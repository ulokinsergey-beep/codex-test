# Инструкции для Codex

Этот файл содержит правила работы с проектом codex-test.

## Основные правила

### 1. Язык общения
- Объясняй все простыми словами
- Избегай сложного технического сленга
- Пользователь не программист — помни об этом
- Если используешь термин, объясни его

### 2. Планирование перед изменениями
- Для крупных изменений СНАЧАЛА предложи план
- Жди подтверждения пользователя перед началом работы
- Не меняй код без явного разрешения
- Объясни риски и возможные проблемы

### 3. Git (ЗАПРЕЩЕНО)
- ❌ Не делай commit
- ❌ Не делай push
- ❌ Не делай pull
- ❌ Не делай merge
- ❌ Не трогай Git вообще

### 4. Создание новых файлов
- Не создавай новые файлы без явного разрешения пользователя
- Если файл нужен — сначала спроси, потом создавай
- Исключение: этот файл (AGENTS.md) и другие явно разрешённые инструкции

### 5. Правило для работы с сайтом
- Если задача касается сайта — меняй ТОЛЬКО `index.html`
- Не создавай отдельные CSS-файлы, JS-файлы и т.д. без разрешения
- Весь код должен быть внутри одного `index.html`

### 6. Объяснение после изменений
После каждой правки кратко объясни:
- ✅ Что изменено (перечисли конкретные изменения)
- ✅ Какие файлы затронуты (например, index.html)
- ✅ Как проверить результат (откройи файл в браузере, перезагрузи и т.д.)

### 7. Внешние зависимости
- ❌ Не добавляй npm-пакеты, библиотеки, фреймворки
- ❌ Не подключай CDN или внешние скрипты без отдельного согласования
- ✅ Используй только встроенный HTML, CSS, vanilla JavaScript

### 8. Безопасность
- ❌ Никогда не вставляй API-ключи в код
- ❌ Никогда не вставляй пароли в код
- ❌ Никогда не вставляй токены в код
- ❌ Никогда не вставляй другие секреты в код
- Если нужны секреты — спроси, как их обработать безопасно

## Cursor Cloud specific instructions

- **Project type:** Single-file static HTML site. No dependencies, no build step, no package manager.
- **Dev server:** Run `python3 -m http.server 8080` from `/workspace` to serve the site locally at `http://localhost:8080/index.html`.
- **Lint/test:** No linter or test framework configured. Validate by opening in browser and checking rendering.
- **All code lives in `index.html`** — inline CSS and vanilla JS only (per project rules above).

## Как использовать этот файл

Этот файл читается автоматически и задаёт правила для всех операций с проектом. Пользователю не нужно напоминать эти правила — Codex будет их соблюдать.
